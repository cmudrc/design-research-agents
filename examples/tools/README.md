## Tool Runtime Examples

Run from repo root:

```bash
PYTHONPATH=src python3 examples/tools/mcp_minimal.py
PYTHONPATH=src python3 examples/tools/source_fusion_story.py
```

Notes:
- `mcp_minimal.py` demonstrates a minimal MCP-only runtime and namespaced tool calls.
- `source_fusion_story.py` demonstrates one scenario that combines core tools, lazy tools, and MCP tools.
