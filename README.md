# design-research-agents

Opinionated Python scaffolding for building and researching agentic systems.

## Quickstart

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e ".[dev]"
make test
make run-example
```
